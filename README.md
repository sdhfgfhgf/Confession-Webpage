💖 Confession Webpage

A personalized, animated HTML/CSS love confession webpage. 
This project blends heartfelt messages with responsive design and CSS-based animation, creating a unique and emotionally expressive experience.


⸻

🌸 Features
	-	💘 Animated Heartbeat Visuals
Smooth CSS keyframe animations create a pulsing heart effect, symbolizing love and emotion.
	-	💬 Bilingual Poetic Text
Romantic messages in both Simplified Chinese and English express personal feelings in a direct and poetic format.
	-	🎨 Themed Design
Gentle color palettes and soft gradients reflect the tone of sincerity and affection.
	-	📱 Responsive Layout
Optimized for modern browsers and devices using semantic HTML and fluid layout principles.

⸻

🧰 Built With
	-	HTML5
	-	CSS3 (no JavaScript)
	-	Designed for deployment on GitHub Pages or any static web host

⸻

💡 Learning Highlights
	-	Practiced advanced CSS animations using @keyframes
	-	Explored expressive UI design through emotion-driven layout and typography
	-	Built a completely JavaScript-free, interactive visual experience

⸻

🚀 How to Use
1.	Clone the repository:

		git clone https://github.com/sdhfgfhgf/Confession-Webpage.git


2.	Open My_Confession.html or index.html in any modern web browser.
3.	Optionally deploy to GitHub Pages or another static site host.
